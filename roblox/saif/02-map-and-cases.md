# 02 — الخريطة ومحتوى القضايا

## الخريطة: «مدرسة الأمل» — طابق واحد، ٦ مواقع

مساحة مضبوطة عمدًا: صغيرة بما يكفي للبناء في أيام، وكبيرة بما يكفي لإخفاء الأدلة.

```
┌──────────────────────────────────────────────────┐
│  الفصل — حاسب آلي  │   البهـــو   │ غرفة الخوادم │
├──────────────────────────────────────────────────┤
│                   الســــاحة                      │
├──────────────────────────────────────────────────┤
│      المقصــف       │        المكتبــة            │
└──────────────────────────────────────────────────┘
```

| الموقع | دوره في التحقيق |
|---|---|
| الفصل — حاسب آلي | أجهزة، حقائب، أدلة مادية |
| البهو | كاميرا الممر — الأدلة الزمنية |
| غرفة الخوادم | السجلات وأوقات الدخول |
| الساحة | لقاء الشهود ومنطقة الشراكة |
| المقصف | الهواتف، الرسائل، شبكة الواي فاي العامة |
| المكتبة | الأجهزة المشتركة وسجل التصفح |

**تكلفة البناء:** أشكال Roblox أساسية + إضاءة + ألوان. **بلا أي نموذج خارجي** — وهذا يحل مشكلة التراخيص من جذرها ويبقي الأداء عاليًا على الجوال.

## القضية ١ — الحساب المسروق ✅ (مبنية في النموذج التفاعلي)

**الحادثة:** حساب سارة على منصة المدرسة نشر كلامًا لم تكتبه. النظام يقول: لا اختراق، الدخول تمّ بكلمة السر الصحيحة.

**الأدلة الخمسة**

| # | النوع | الموقع | الدليل |
|---|---|---|---|
| 1 | رقمي | المقصف | رسالة «مبروك! فزت ببطاقة ألعاب — سجّل دخولك» |
| 2 | رقمي | غرفة الخوادم | سجل دخول ناجح ٣:٤٧م من جهاز غير معروف |
| 3 | مادي | الفصل | ورقة في الحقيبة مكتوب عليها كلمة السر |
| 4 | مادي | البهو | كاميرا: خالد استعمل الجهاز ١:١٥م |
| 5 | رقمي | المكتبة | العنوان: `school-p0rtal-login.co` بدل `portal.school.sa` |

**الشهود الثلاثة**
- **سارة** (المتضررة): «فتحت الرسالة وسجّلت دخولي عشان آخذ الجائزة.»
- **خالد** (زميل): «استعملت جهازها وقت الفسحة ورجّعته.» ← **الكاميرا تبرّئه**: ١:١٥م لا ٣:٤٧م.
- **أ. منى** (معلمة الحاسب): «لا اختراق في النظام — الدخول بكلمة سر صحيحة.»

**الحل:** الرابط المزيّف (تصيّد). لا جاني من البشر داخل المدرسة.
**القاعدة ٠١:** *افحص الرابط قبل كلمة السر.* — `p0rtal` بصفر ليست `portal` بحرف O، والجائزة التي تطلب كلمة سرّك طُعم.

## القضية ٢ — الصورة المُسرَّبة

**الحادثة:** صورة نشرتها فاطمة في حسابها العام، وبعد يومين وصلها من يذكر اسم حيّها ومدرستها.

**الأدلة:** شارة المدرسة ظاهرة في خلفية الصورة · اسم الشارع في لافتة خلفها · الحساب عام لا خاص · تعليق يسأل «وين مدرستك؟» · بيانات الموقع المرفقة بالصورة.

**الحل:** لم يخترق أحد شيئًا — **الصورة نفسها أفشت كل شيء**.
**القاعدة ٠٢:** *قبل النشر، انظر إلى الخلفية لا إلى وجهك فقط.*

---

## القضية ٣ — الصديق الذي لم يكن

**الحادثة:** «أحمد» يضيف طلابًا في لعبة ويعدهم بعناصر مجانية مقابل «رمز التحقق» الذي يصلهم.

**الأدلة:** حساب عمره ٣ أيام · صورة الملف مأخوذة من حساب آخر · نفس الرسالة الحرفية أُرسلت لـ٧ طلاب · طلب الرمز · لا أصدقاء مشتركين حقيقيون.

**الحل:** انتحال هوية وسرقة حساب عبر رمز التحقق.
**القاعدة ٠٣:** *رمز التحقق لك وحدك — من يطلبه ليس صديقًا مهما بدا.*

## محرّك القضايا — نقطة «الاستدامة المستقبلية»

كل قضية ملف بيانات واحد لا كود:

```
Case = {
  id, title, brief,
  clues   = { id, kind("digital"|"physical"), room, name, text },
  people  = { id, name, role, quote, unlockedBy, exonerates },
  threads = { id, label, takes = { clueIds } },
  suspects= { id, name, sub },
  answer, lesson, rule
}
```

**النتيجة:** معلّم أو طالب يضيف قضية جديدة بتعبئة جدول — بلا مبرمج وبلا إعادة بناء. هذا بالضبط ما يُكتب تحت «الاستدامة» في الملصق، وهو ادعاء **قابل للإثبات أمام المحكّم في ثلاثين ثانية**.
