# ملف السلام الملكي

ضعي ملف السلام الملكي هنا باسم:

```
national-anthem.mp3
```

يتعرّف النظام على الملف تلقائيًا عند وجوده ويُفعّل المشغّل في ترويسة
لوحة الإدارة (تشغيل / إيقاف مؤقت / إيقاف / كتم / مستوى الصوت).

**لم يُرفق ملف الصوت مع بيانات المشروع**، ولذلك يعرض النظام حاليًا
«السلام الملكي: الملف غير مرفوع» بدل تشغيل نسخة بديلة.

ملاحظات:

- تُستخدم نسخة صوتية واحدة فقط في الذاكرة، فلا يحدث تشغيل مزدوج.
- إذا منع المتصفح التشغيل التلقائي، يُطلب من المستخدمة الضغط على «تشغيل»
  بدل الالتفاف على قيود المتصفح.
- المشغّل مخفي في الطباعة وفي التقارير، ولا يظهر إطلاقًا في القياس العام.
