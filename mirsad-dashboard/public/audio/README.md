# السلام الملكي

`national-anthem.mp3` — مُثبَّت وجاهز. يتعرّف عليه النظام تلقائيًا ويُفعّل
المشغّل في ترويسة لوحة الإدارة (تشغيل · إيقاف مؤقت · إيقاف · كتم · مستوى الصوت).

## المعالجة المطبَّقة

شُخِّص الملف الأصلي بالقياس لا بالافتراض:

| الفحص | النتيجة |
| --- | --- |
| هسيس | لا يوجد — أرضية الضوضاء ‎-70 dB عند ٢–٤ كيلوهرتز |
| طنين كهربائي ٥٠/٦٠ هرتز | لا يوجد |
| قصّ صلب | لا يوجد — صفر عيّنة مثبّتة عند السقف |
| **تجاوز بين-عيّني** | **‎+1.08 dBFS في ١٣١ ومضة** ← مصدر التشويش |

التشويش المسموع سببه تجاوز الذروة فوق السقف الرقمي، يقصّه المشغّل عند
التشغيل فيُسمَع طقطقةً. لذلك **لم تُطبَّق أي تنقية ضوضاء طيفية** — هي تُتلف
تسجيلًا نظيفًا بلا فائدة.

قُوبل خفض الكسب العام بالتحديد الجراحي قياسًا:

```
خفض كسب عام      → فرق الموجة عن الأصل  -240 dB   (مطابقة رقمية)
تحديد جراحي      → فرق الموجة عن الأصل   -28 dB   (تشويه محتمل)
```

فاعتُمد الخفض العام: يمنح الهامش الآمن ويُبقي النشيد كما سُجّل تمامًا.

السلسلة: إزالة إزاحة التيار المستمر ← تمرير عالٍ ٢٠ هرتز ← خفض كسب
‎-2.26 dB ← تلاشٍ ١٢ ms في الطرفين ← ترميز MP3 بجودة المصدر نفسها، ثم
إعادة قياس الناتج المفكوك والتكرار حتى تستقر الذروة تحت ‎-1 dBTP.

| | قبل | بعد |
| --- | --- | --- |
| الذروة الحقيقية | ‎+1.08 dBTP | **‎-0.99 dBTP** |
| عيّنات متجاوزة | ٦٢٠ | **٠** |
| المدة · العيّنات · القنوات | ٣٥٫٩٠s · 44.1 kHz · ستيريو | بلا تغيير |
| معدل البت | ١٣٦ kbps | ١٣٥ kbps |
| الارتباط بالمصدر | — | **٠٫٩٩٩٤** |

الفرق في كل نطاقات الطيف = خفض الكسب نفسه (‎≈ -2.3 dB)، أي **لم يتضرّر أي نطاق**.

## إعادة الإنتاج

```bash
python3 scripts/audio/clean_anthem.py <الملف-الأصلي> public/audio/national-anthem.mp3 /tmp/master.wav
```

## السلوك في النظام

- نسخة صوتية واحدة في الذاكرة — لا تشغيل مزدوج (تحقّق آلي: `instances: 1`).
- إن منع المتصفح التشغيل التلقائي، يُطلب ضغط «تشغيل» بدل الالتفاف على القيد.
- مخفي في الطباعة والتقارير، وغائب تمامًا عن القياس العام للطالبات.
