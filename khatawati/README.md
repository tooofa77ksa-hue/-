# خطواتي - ملف إنجاز رقمي تفاعلي

منصة ملف إنجاز رقمي لطالبات الصف الثالث - الابتدائية الخامسة والستون بعد
المائة. **مشروع منفصل تمامًا عن "شُعلة لغتي"** - كود مستقل، قاعدة بيانات
Firebase مستقلة، رابط استضافة مستقل. لا يوجد أي ارتباط بينهما.

## الحسابات

| الدور | تشوف | تقدر تعدّل |
|---|---|---|
| كل طالبة (٨ حسابات، تدخل الأم مع بنتها بنفس الحساب) | ملفها هي فقط | نبذتها، اهتماماتها، صورتها، لون ملفها، اسمها المعروض، شهاداتها، إنجازاتها، وأعمال المواد الست |
| معلمة لغتي (دلال السناني) | كل الطالبات وكل الأقسام | تقييم أعمال قسم **لغتي** فقط (نجمة + عبارة) |
| معلمة رياضيات (سميرة الشريف) | كل الطالبات وكل الأقسام | تقييم أعمال قسم **رياضيات** فقط |
| معلمة الإنجليزي (عائشة البلادي) | كل الطالبات وكل الأقسام | تقييم أعمال قسم **الإنجليزي** فقط |
| معلمة العلوم (حنان العمري) | كل الطالبات وكل الأقسام | تقييم أعمال قسم **العلوم** فقط |
| معلمة الدراسات الإسلامية (بدرية السفري) | كل الطالبات وكل الأقسام | تقييم أعمال قسم **الدراسات الإسلامية** فقط |
| معلمة مهارات حياتية (عبير المطيري) | كل الطالبات وكل الأقسام | تقييم أعمال قسم **مهارات حياتية** فقط |

بيانات الدخول (بعد تشغيل `npm run seed` - راجعي الأسفل): اسم المستخدم بسيط
بالإنجليزي (مثل `nadeen`)، وكلمة السر = أول حرف اسمها بالإنجليزي + `12345`
(مثال: `N12345`). **ملاحظة مهمة**: طلب أصلي بكلمة سر أقصر (حرف + 123) لكن
Firebase يرفض أي كلمة سر أقل من 6 خانات - هذا قيد من فايربيس نفسه، مافيه
تحايل عليه. كلمات سر المعلمات الست أقوى (مثل `Dalal#2025`، نفس النمط
لكل معلمة باسم أول حرف من اسمها - راجعي `scripts/seed.ts`) لأن حسابهن
يشوف كل الطالبات.

## قبل أول استخدام حقيقي - 3 خطوات في Firebase Console (مرة وحدة فقط)

1. **أنشئي مشروع Firebase جديد**: اذهبي إلى https://console.firebase.google.com
   واضغطي "Add project" - سمّيه مثلًا "khatawati-165". هذا مشروع منفصل
   تمامًا عن مشروع شعلة لغتي.
2. **فعّلي Authentication**: من القائمة الجانبية → Authentication → Get
   started → فعّلي طريقة "Email/Password".
3. **فعّلي Firestore**: من القائمة الجانبية → Firestore Database → Create
   database → اختاري أي موقع قريب (مثل `eur3` أو `me-central1`) → ابدئي
   بوضع الإنتاج (Production mode) - قواعد الأمان الجاهزة في المشروع
   (`firestore.rules`) هي اللي تحمي البيانات، لسنا محتاجين "test mode".

بعدها من "Project settings" (⚙️) → "Your apps" → أضيفي تطبيق ويب (Web)،
وانسخي القيم إلى ملف `.env` (انسخي `.env.example` وسمّيه `.env`).

## تشغيل أول مرة (من جهاز فيه Node.js)

```bash
cd khatawati
npm install
cp .env.example .env   # واملئي القيم من Firebase Console
```

نشر قواعد الأمان والفهارس على مشروعك الحقيقي (مرة واحدة، ومرة أخرى بعد أي
تعديل لاحق على `firestore.rules`):

```bash
npx firebase login
npx firebase use --add   # اختاري مشروع Firebase الجديد وسمّيه alias "production"
npm run deploy:rules
```

إنشاء الحسابات الثمانية + المعلمتين على مشروعك الحقيقي:

```bash
npm run seed
```

بناء الموقع ونشره (Firebase Hosting - مجاني):

```bash
npm run build
npm run deploy:hosting
```

## الأغنية المشتركة

ضعي ملف الأغنية باسم `public/audio/theme.mp3` قبل البناء (يشتغل تلقائيًا
عند فتح أي صفحة، مع زر كتم/تشغيل ثابت في الزاوية). الموقع يعمل طبيعيًا
حتى بدون الملف - فقط بلا صوت فعلي.

## التطوير المحلي بمحاكي Firebase (بدون لمس أي بيانات حقيقية)

```bash
npm run emulator                                    # نافذة 1
FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 FIREBASE_AUTH_EMULATOR_HOST=127.0.0.1:9099 \
  GCLOUD_PROJECT=demo-khatawati npm run seed         # نافذة 2
npm run dev                                          # (مع VITE_USE_FIREBASE_EMULATORS=true في .env)
```

فحص قواعد الأمان تلقائيًا (18 اختبارًا يغطي عزل الطالبات وتقييد كل معلمة
بمادتها فقط):

```bash
npm run test:rules
```

## التكلفة

كل شي في هذا المشروع (Firestore + Hosting + Authentication) على الخطة
المجانية (Spark) من Firebase - لا يوجد استخدام لـ Firebase Storage عمدًا
(الصور تُحفَظ مضغوطة داخل قاعدة البيانات نفسها) حتى لا نحتاج ترقية لخطة
مدفوعة.
