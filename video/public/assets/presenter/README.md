# طبقة المذيعة (Presenter Layer)

لا يمكن توليد شخصية بشرية واقعية تتحدث وتحرك شفتيها بدقة داخل بيئة عمل
Remotion وحدها. طبقة `src/components/Presenter/Presenter.tsx` مصمَّمة
لهذا بالضبط: هي طبقة **مستقلة تمامًا** عن باقي المشهد (لا تتحكم إلا
بموضعها وإيماءتها)، وتعرض حاليًا بديلًا تجريديًا محتشمًا (سيليويت بدرجات
هوية الوزارة، بلا ملامح مرسومة وبلا طابع كرتوني) إلى حين توفير فيديو
Avatar حقيقي.

## طريقة الاستبدال (بدون تعديل أي مشهد آخر)

1. أنتجي فيديو مذيعة عربية محتشمة بعباية أنيقة، إما:
   - بقناة ألفا شفافة (WebM VP9 مع alpha، أو ProRes 4444)، أو
   - بخلفية خضراء (Green Screen) تُعالَج لاحقًا بأداة Chroma Key خارجية
     وتُصدَّر بصيغة شفافة.
2. ضعي الملف هنا، مثلًا: `public/assets/presenter/host.webm`.
3. مرّري مسار الملف عبر الخاصية `videoSrc="assets/presenter/host.webm"`
   عند استدعاء `<Presenter />` في ملفات المشاهد
   (`src/compositions/scenes/**`) - سطر واحد لكل مشهد، بلا أي تعديل على
   بنية المكوّن نفسه.

الإيماءات المدعومة حاليًا في الواجهة (`gesture` prop) وتُطبَّق تلقائيًا
على الفيديو الحقيقي بمجرد إضافته: `idle`, `lookingAtCamera`, `pointing`,
`turnedToCard`.
