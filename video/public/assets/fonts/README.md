# خط الهوية الرسمي

خط الهوية الرسمي لوزارة التعليم "Helvetica Neue W23 for SKY" مرخّص وغير
متاح في هذه البيئة. تم استخدام **Tajawal** (خط عربي عام مجاني، Google
Fonts) كبديل بصري مناسب، بنفس الطريقة المستخدمة في تطبيق "شُعلة لغتي"
الشقيق داخل هذا المستودع (`src/styles/theme.css`).

## لاستبدال الخط لاحقًا بالخط الرسمي

1. ضعي ملفات الخط (`.woff2` أو `.ttf`) هنا داخل هذا المجلد.
2. عدّلي `video/src/styles/fonts.ts` لتحميل الخط عبر `@remotion/fonts` أو
   `@font-face` مباشرة بدلًا من `@remotion/google-fonts/Tajawal`.
3. لا حاجة لتعديل أي مكوّن آخر - جميع المكوّنات تستورد `arabicFontFamily`
   من نفس الملف.
