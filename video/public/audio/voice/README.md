# فتحات التعليق الصوتي (Voiceover Slots)

لا يتوفر في بيئة العمل الحالية أي مزود صوت عربي نسائي فصيح عالي الجودة
(لا اتصال بمزوّدي TTS السحابيين، ولا نماذج صوت محلية عالية الجودة قابلة
للتحميل بسبب سياسة الشبكة) - لذلك لم تُدرَج ملفات صوتية اصطناعية رديئة
بدلًا عنها، لأن ذلك يخالف صراحة متطلبات الجودة المطلوبة (صوت نسائي فصيح،
رسمي، هادئ وواثق، غير آلي الطابع). المشروع جاهز بالكامل لقراءة الملفات
التالية فور إضافتها بصيغة **MP3 (44.1kHz)** بدون أي تعديل على الكود -
مدة كل مشهد وتوقيت كل حركة تُحسب تلقائيًا من طول الملف الفعلي
(`src/audio/getVoiceDuration.ts` + `src/timeline.ts`). إلى أن تُضاف
الملفات، تُستخدم مدة تقديرية من عدد الكلمات لمعاينة التوقيت فقط.

ضعي الملفات بهذه الأسماء بالضبط هنا. النص الكامل المطلوب تسجيله لكل ملف
موجود في `src/data/voiceover-scripts.ts` (حقل `text`) - وهو مبني حصرًا
على أرقام بطاقتَي نافس الرسميتين المرفقتين، بلا أي ادعاء غير مدعوم بالبيانات.

| الملف | المشهد | الدور |
|---|---|---|
| `intro_01.mp3` | Intro | افتتاحية باسم الوزارة |
| `third_intro_01.mp3` | NafesThird | تقديم بطاقة الصف الثالث |
| `third_trend_01.mp3` | NafesThird | شرح تطور النتيجة عبر الأعوام الثلاثة |
| `third_subjects_01.mp3` | NafesThird | مقارنة الرياضيات والقراءة |
| `third_summary_01.mp3` | NafesThird | خاتمة قصيرة |
| `transition_01.mp3` | Transition | جملة الانتقال إلى السادس |
| `sixth_intro_01.mp3` | NafesSixth | تقديم بطاقة الصف السادس |
| `sixth_trend_01.mp3` | NafesSixth | شرح تطور النتيجة عبر الأعوام الثلاثة |
| `sixth_subjects_01.mp3` | NafesSixth | مقارنة العلوم والقراءة والرياضيات |
| `sixth_summary_01.mp3` | NafesSixth | خاتمة قصيرة |
| `outro_01.mp3` | Outro | خاتمة الفيديو |

## طريقة الإضافة

أي من الطريقتين تعمل فور توفرها، بدون أي تعديل على الكود:

1. تسجيل الجمل أعلاه بصوت معلِّقة صوتية عربية فصيحة حقيقية.
2. توليدها عبر خدمة TTS عربية نسائية عالية الجودة (مثل ElevenLabs أو
   Google Cloud Text-to-Speech) خارج هذه البيئة، ثم رفع ملفات MP3 الناتجة
   هنا بنفس الأسماء بالضبط.

انتبهي للنطق الصحيح لـ: نافس، الصف الثالث الابتدائي، الصف السادس
الابتدائي، النسب المئوية، الأعوام (بالتقويم الهجري وفق البطاقة)،
المؤشرات، النتائج - كما وردت في نص كل ملف.
