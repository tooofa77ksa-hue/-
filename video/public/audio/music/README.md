# موسيقى الخلفية (Music Bed)

لا يتوفر في بيئة العمل الحالية أي مصدر موسيقى Instrumental مرخّصة
(Corporate/Cinematic/Governmental) يمكن تنزيله أو توليفه بجودة تصلح لعرض
وزاري - توليد موسيقى مقنعة يتطلب أدوات تأليف/عزف غير متاحة هنا، وأي بديل
مُركَّب إجرائيًا سيبدو رقميًا رديئًا ويخالف متطلبات الجودة "Corporate
cinematic, Modern governmental presentation, Elegant technology, Minimal
inspirational" المطلوبة صراحة.

النظام جاهز بالكامل لتشغيل الموسيقى بمجرد إضافتها، بما في ذلك خفض
مستواها تلقائيًا أثناء حديث المذيعة (Audio Ducking) - انظر
`src/audio/MusicBed.tsx`.

## طريقة الإضافة

ضعي مقطوعة واحدة بصيغة MP3 بهذا الاسم بالضبط:

```
theme.mp3
```

يُفضَّل مقطوعة مستمرة بلا كلمات، طولها لا يقل عن طول الفيديو الكامل
(يظهر الطول الإجمالي بالإطارات في وحدة تحكم Remotion Studio عند تشغيل
`npm run dev`). لا حاجة لقص الملف يدويًا - يتم قصّه تلقائيًا حسب مدة
الفيديو الفعلية.

مصادر مناسبة: مكتبات موسيقى خالية من حقوق الملكية (Royalty-free) بترخيص
تجاري واضح، أو تأليف أصلي.
