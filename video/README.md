# فيديو Motion Graphics - بطاقة نافس

مشروع [Remotion](https://remotion.dev) لتحويل بطاقات نافس الرسمية (وزارة التعليم) إلى فيديو Motion Graphics متحرك، مبني على بيانات حقيقية موثّقة رقمًا برقم.

## الحالة الحالية

- **الصف الثالث الابتدائي**: مكتمل (`src/Grade3Nafs.tsx`) - بانتظار الاعتماد قبل البدء بالصف السادس.
- **الصف السادس الابتدائي**: لم يبدأ بعد.

## المرجع الثابت

`reference/grade3-nafs-card.pdf` هو ملف PDF الأصلي كما ورد من نظام نافس، و`reference/grade3-pages/*.png` نسخ مُصدَّرة من صفحاته للمراجعة البصرية السريعة. **كل رقم** في `src/data/grade3.ts` تم التحقق منه مقابل هذا الملف (وفي حالات التداخل، مقابل تصدير عالي الدقة منه) قبل استخدامه في أي رسم متحرك - راجع التعليق في أعلى ذلك الملف لتفاصيل نطاق البيانات المُستبعدة (نقطتان متداخلتان في PDF نفسه).

## البنية

```
src/
  data/grade3.ts        - كل بيانات الصف الثالث (المصدر الوحيد للحقيقة)
  brand/tokens.ts        - ألوان وخط الهوية (من theme.css في جذر المستودع)
  components/            - عناصر Motion قابلة لإعادة الاستخدام (عدّاد أرقام، مخطط خطي، شريط توزيع، ...)
  scenes/                - مشاهد الفيديو (مقدمة، مؤشر عام، مادة دراسية، خاتمة)
  Grade3Nafs.tsx          - التركيب النهائي لفيديو الصف الثالث (TransitionSeries)
public/
  ministry-logo.webp     - الشعار الرسمي (بلا أي تعديل)
  fonts/Tajawal-*.ttf     - خط الهوية العربي، مُحمَّل محليًا لضمان استقرار الرندر
  audio/                  - مؤثرات صوتية (whoosh/tick/impact) مولَّدة بـ ffmpeg، بلا اعتماد على مصدر خارجي
```

## الأوامر

```console
npm i                 # تثبيت الاعتماديات
npm run dev           # فتح Remotion Studio للمعاينة التفاعلية
npx remotion render Grade3Nafs out/grade3-nafs-preview.mp4   # تصدير فيديو الصف الثالث (1920x1080، 30fps)
```

## ملاحظة على بيئة الرندر

Chromium الافتراضي لـ Remotion (المُنزَّل من `remotion.media`) قد لا يكون متاحًا في كل بيئة شبكية. عند الحاجة، يمكن توجيه Remotion لاستخدام أي Chromium/Chrome headless متاح محليًا عبر `Config.setBrowserExecutable(...)` في `remotion.config.ts`.
