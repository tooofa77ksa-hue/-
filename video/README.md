# فيديو نتائج نافس - وزارة التعليم (Remotion)

فيديو Motion Graphics رسمي قابل للتوسعة، مبني بـ [Remotion](https://www.remotion.dev)،
يستعرض نتائج اختبارات نافس (الصف الثالث والسادس الابتدائي) اعتمادًا على
بطاقتَي نافس الرسميتين المرفقتين فقط - بلا أي رقم مُخترَع.

- **المقاس**: 1920×1080 (Full HD)، 16:9، 30fps.
- **الإخراج**: MP4 (H.264، CRF منخفض لجودة عالية).
- **اللغة**: عربية فصحى، اتجاه RTL صحيح في كل النصوص.

## التشغيل السريع

```bash
cd video
npm install
npm run dev       # يفتح Remotion Studio للمعاينة التفاعلية
npm run render    # يصدّر out/nafes-video.mp4
```

> إن كانت بيئتك تمنع Remotion من تنزيل Chromium الخاص به (سياسة شبكة
> معزولة)، مرّري متغيّر البيئة `REMOTION_BROWSER_EXECUTABLE` بمسار أي
> Chromium/Chrome headless مثبَّت مسبقًا لديك قبل أوامر `dev`/`render`/`still`.

## حالة المشروع الآن

كل شيء **حقيقي وعامل فعليًا**: البيانات، التوقيت، الرسوم المتحركة،
المزامنة، الشعار، الخط، بنية المشاهد. الأجزاء التالية فقط بانتظار ملفات
لم تُرفع بعد (المشروع مصمَّم ليعمل بدونها بأناقة، ويلتقطها تلقائيًا
فور إضافتها بلا أي تعديل على الكود):

| العنصر | الحالة | كيف يُكتمل |
|---|---|---|
| التعليق الصوتي (مذيعة) | تقدير مدة من عدد الكلمات فقط | أضيفي ملفات MP3 في `public/audio/voice/` - راجعي `public/audio/voice/README.md` |
| فيديو المذيعة (Avatar) | سيليويت تجريدي بديل مؤقت | أضيفي فيديو شفاف/Green-Screen - راجعي `public/assets/presenter/README.md` |
| الموسيقى الخلفية | لا تُشغَّل (لا ملف) | أضيفي `public/audio/music/theme.mp3` - راجعي `public/audio/music/README.md` |
| المؤثرات الصوتية (SFX) | **مولَّدة إجرائيًا وجاهزة** (`npm run make-sfx`) | لا حاجة لأي شيء - تعمل الآن |
| شعار الوزارة | **حقيقي وجاهز** (منسوخ من هوية المستودع) | لا حاجة لأي شيء |
| خط Tajawal العربي | **محلي وجاهز** (بلا اتصال شبكي وقت الرندر) | لا حاجة لأي شيء |
| بيانات نافس (ثالث/سادس) | **حقيقية من الملفين المرفقين** | لتحديثها لاحقًا عدّلي `src/data/nafes-*.ts` فقط |

لماذا لم تُنشأ ملفات الصوت/الفيديو الحقيقية في هذه البيئة تحديدًا: لا
يوجد اتصال بأي مزود TTS أو توليد فيديو Avatar (سياسة شبكة العمل)، وأي
بديل اصطناعي رديء يخالف صراحة متطلبات الجودة الرسمية المطلوبة - نفس
القرار المتّبع في تطبيق "شُعلة لغتي" الشقيق داخل هذا المستودع
(`public/audio/voice/README.md` في جذر المستودع).

**ملاحظة Console متوقَّعة:** أثناء `npm run dev` أو `npm run render` سترين
رسائل 404 لملفات مثل `audio/voice/intro_01.mp3` في الطرفية/الـ Console -
هذا سلوك متعمَّد (فحص وجود الملف الاختياري بأمان)، وليس خطأ يوقف أي شيء؛
يختفي تلقائيًا بمجرد إضافة الملف الحقيقي.

      Intro/ NafesThird/ Transition/ NafesSixth/ Outro/

## إضافة قسم/مشهد جديد مستقبلًا

المشروع مُصمَّم خصيصًا لهذا (إحصاءات مدرسة، إنجازات، مرافق، صور،
NotebookLM، برامج، ورش...) دون كسر أي شيء سابق:

1. أضيفي بيانات القسم الجديد في `src/data/` (ملف TS جديد، بنفس نمط
   `nafes-third.ts`).
2. أضيفي نصوص التعليق الصوتي له في `src/data/voiceover-scripts.ts`.
3. أنشئي مكوّن المشهد في `src/compositions/scenes/<اسم القسم>/index.tsx`
   (يمكنه إعادة استخدام `components/*` الحالية أو إضافة مكوّنات جديدة
   بنفس البنية).
4. أضيفي عنصرًا واحدًا جديدًا في `SCENE_DEFINITIONS` داخل `src/timeline.ts`
   بترتيب ظهوره.
5. اربطي المكوّن في `src/MainVideo.tsx` ضمن `<TransitionSeries>` (Sequence
   جديد + Transition).

مدة كل مشهد تُحسب تلقائيًا من مدة صوته الفعلية - لا حاجة لضبط أي رقم
توقيت يدويًا، ولا يتأثر توقيت أي مشهد سابق.

## دقة بيانات نافس

جميع الأرقام في `src/data/nafes-third.ts` و`nafes-sixth.ts` منقولة
حرفيًا من `public/assets/nafes/nafes-*-source.pdf` (بطاقتا نافس
الرسميتان المرفقتان، منصة se.etec.gov.sa). البطاقتان تتضمنان أيضًا
رسومًا إضافية (توزيع مستويات الأداء، ومقارنات المدرسة/إدارة
التعليم/المملكة لكل مجال فرعي) لم تُدرَج في الفيديو حاليًا لأن استخراجها
النصي الآلي من PDF لا يضمن مطابقة كل رقم للون/الفئة الصحيحة بدقة كافية
لعرض وزاري رسمي - راجعي `notes` في كل ملف بيانات، وأضيفيها لاحقًا يدويًا
بالرجوع إلى ملف PDF المصدر مباشرة إن رغبتِ بذلك.

## المعاينة والتحقق قبل الرندر النهائي

```bash
npm run typecheck   # فحص TypeScript كامل
npm run dev          # Remotion Studio - راجعي RTL، الهوامش الآمنة، تداخل المذيعة مع البيانات
```

تم التحقق فعليًا (render/still headless) من: سلامة الخط العربي وعدم
انعكاسه/تقطّعه، عدم خروج النصوص عن حدود 1920×1080، عدم تداخل المذيعة مع
البيانات، مزامنة الأرقام مع الأعمدة، وضوح الشعار وثباته، ونجاح رندر
MP4 كامل بلا أخطاء توقف التنفيذ.
