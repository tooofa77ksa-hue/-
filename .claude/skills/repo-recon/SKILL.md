# repo-recon — استكشاف المستودع

## متى تعمل
- أول مهمة في مستودع أو مجلد جديد.
- قبل أي تعديل في منطقة غير مألوفة.
- عند بدء جلسة في حاوية جديدة.

## النطاق
**قراءة فقط.** لا تعديل، لا حذف، لا تثبيت، لا تشغيل أوامر ذات أثر جانبي أثناء الاستكشاف.

## الخطوات

### 1. الموقع والحالة (30 ثانية)
```
pwd · git branch --show-current · git status --short · git log --oneline -10
```
اعرف: أين أنا · أي فرع · هل فيه تغييرات غير ملتزمة · ماذا حدث مؤخرًا.

### 2. الشكل
```
ls -la · مانيفست المشروع (package.json / pyproject.toml / Cargo.toml / *.csproj)
```
استخرج: التقنية · **أوامر البناء والاختبار والفحص** · نقاط الدخول.

### 3. القواعد المحلية — **الأولوية العليا**
ابحث عن `CLAUDE.md` (الجذر والمجلدات الفرعية) · `.claude/skills/` · `CONTRIBUTING.md` · `.github/workflows/`.
**قواعد المشروع تعلو على عاداتي.**

### 4. الأدوات المتاحة
افحص ما هو مثبّت فعلًا قبل أن تفترض. أداة ناقصة = اقتراح للمستخدم، لا تثبيت تلقائي.

### 5. المنطقة المستهدفة
ابحث عن الملفات ذات الصلة بالمهمة، واقرأ **الأنماط المحيطة** قبل الكتابة: التسمية، كثافة التعليقات، أسلوب معالجة الأخطاء، بنية الاختبارات. الكود الجديد يجب أن يشبه جيرانه.

### 6. المخاطر
سجّل: ملفات حساسة (قواعد أمان، هجرات، إعدادات نشر) · ما لا يجب لمسه · هل البيئة مؤقتة.

## معايير القبول
- أعرف الفرع الحالي وحالة الشجرة قبل أول تعديل.
- قرأت كل `CLAUDE.md` في المسار.
- أعرف أمر الاختبار والفحص في هذا المشروع بالضبط.
- أعرف نمط الكود المحيط قبل الكتابة.

## اختبارات التحقق
- هل أستطيع وصف هذا المشروع في ثلاث جمل؟
- هل أستطيع تشغيل اختباراته من الذاكرة؟
- هل أعرف ما الذي سيكسره تعديلي؟

## المحظورات
- ممنوع تعديل أو حذف أي ملف أثناء الاستكشاف.
- ممنوع تثبيت أي شيء لمجرد «تجربته».
- ممنوع تشغيل أوامر ذات أثر (`build`, `migrate`, `deploy`, `npm i`) في مرحلة الاستكشاف.
- ممنوع افتراض التقنية من اسم المجلد — افحص المانيفست.
- ممنوع القراءة من مستودع خارج نطاق الجلسة المصرّح به.
