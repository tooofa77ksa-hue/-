# shualat-lughati-web — مشروع الويب في الجذر

## متى تعمل
- أي تعديل في `src/` أو `tests/` أو `scripts/` أو `public/`.
- أي تعديل في `firestore.rules` أو `firebase.json` أو الفهارس.
- قبل أي نشر (rules أو hosting).

> ⚠️ هذه المهارة **لا تخص** مجلد `roblox/` — له دستوره الخاص في `roblox/CLAUDE.md`. لا تخلط بين المشروعين.

## التقنية
React 18 · TypeScript 5.6 · Vite 8 · React Router 7 · Firebase 12 · Phaser 3 · Vitest · ESLint.
البنية: `src/{app,components,game,lib,play,teacher,types}` · `tests/rules` · `scripts/`.

## الأوامر

| الغرض | الأمر |
|---|---|
| تطوير | `npm run dev` |
| بناء | `npm run build` (يشغّل `tsc -b` أولًا) |
| فحص الأنواع | `npm run typecheck` |
| فحص الأسلوب | `npm run lint` (**`--max-warnings 0`** — أي تحذير يفشل) |
| محاكي Firebase | `npm run emulator` |
| اختبار القواعد | `npm run test:rules` |
| نشر القواعد | `npm run deploy:rules` |
| نشر الاستضافة | `npm run deploy:hosting` |

## الخطوات

### 1. قبل أي تعديل
اقرأ الملفات المجاورة وطابق أسلوبها: التسمية، بنية المكوّنات، معالجة الأخطاء، ونمط النصوص العربية.

### 2. عند تعديل `firestore.rules` — **أخطر ملف في المشروع**
1. القواعد هي **حدود الأمان الحقيقية** — لا تعتمد على واجهة العميل لمنع شيء.
2. أي تغيير يصحبه اختبار في `tests/rules` يغطي **المسموح والممنوع** معًا.
3. `npm run test:rules` **إلزامي** قبل الالتزام.
4. لا توسيع صلاحية بلا سبب مكتوب. الافتراضي: الرفض.

### 3. عند تعديل الواجهة
النصوص العربية عبر `arabic-first`: RTL صحيح، لا نص مقطوع، مصطلحات موحّدة.

### 4. قبل الالتزام
```
npm run lint && npm run typecheck && npm run build
```
وإن مسست القواعد: `npm run test:rules`.

### 5. النشر
- **لا نشر بلا طلب صريح** من صاحب المشروع.
- القواعد والاستضافة يُنشران منفصلين.
- نشر القواعد يؤثر على الإنتاج فورًا — تأكد من الاختبارات أولًا.

## معايير القبول
- `lint` و`typecheck` و`build` خضراء (صفر تحذيرات).
- أي تغيير في القواعد مغطى باختبار سماح ومنع.
- لا مفاتيح Firebase حقيقية في الكود — من البيئة فقط (`.env.example` بقيم وهمية).
- النصوص العربية سليمة واتجاهها صحيح.

## اختبارات التحقق
- `npm run build` ⇒ ينجح.
- `npm run test:rules` ⇒ أخضر بعد أي تغيير في القواعد.
- افحص الصفحة المتأثرة في المتصفح قبل إعلان الإنجاز.
- `git diff` ⇒ لا تعديل عرضي على ملفات غير مقصودة.

## المحظورات
- ❌ النشر (`deploy:rules` / `deploy:hosting`) بلا إذن صريح.
- ❌ توسيع صلاحيات Firestore بلا اختبار يثبت الحد.
- ❌ مفاتيح أو بيانات اعتماد Firebase في المستودع.
- ❌ بيانات طلاب أو معلمين حقيقية في الاختبارات أو الأمثلة.
- ❌ تعطيل قاعدة lint بدل إصلاح السبب.
- ❌ لمس مجلد `roblox/` من هذه المهارة.
