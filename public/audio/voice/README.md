# فتحات الصوت البشري (Voice Slots)

لا يوجد داخل بيئة العمل مولّد صوت عربي نسائي عالي الجودة، لذا لم نُدرج ملفات
صوتية اصطناعية رديئة. الكود جاهز بالكامل لقراءة الملفات التالية بمجرد
إضافتها هنا بصيغة MP3 (44.1kHz)، بدون أي تعديل على الكود - إن لم يجد الملف
فسيتجاهله بصمت ويكتفي بالمؤثر الصوتي المولَّف.

ضعي الملفات بهذه الأسماء بالضبط داخل هذا المجلد:

| اسم الملف          | يُشغَّل عند       | النص المنطوق              |
|---------------------|--------------------|----------------------------|
| excellent_01.mp3     | EXCELLENT          | «ممتازة!»                 |
| hero_01.mp3          | HERO               | «أحسنتِ يا بطلة!»        |
| amazing_01.mp3       | AMAZING            | «واو! إجابة رائعة!»       |
| star_01.mp3          | STAR               | «نجمة جديدة لك!»         |
| gem_01.mp3           | GEM                | «كنز جديد!»               |
| creative_01.mp3      | CREATIVE           | «أبدعتِ!»                 |
| next_01.mp3          | NEXT_LEVEL         | «إلى المرحلة التالية!»    |
| try_again_01.mp3     | WRONG              | «حاولي مرة أخرى»          |

عبارات إضافية واردة في المتطلبات يمكن دمجها ضمن هذه الفتحات حسب السياق
(مثل «رائعة جدًا!» ضمن EXCELLENT، و«يا سلام!» و«صاروخك جاهز!» ضمن AMAZING).
