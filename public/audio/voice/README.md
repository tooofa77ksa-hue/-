# فتحات الصوت البشري (Voice Slots)

لا يوجد داخل بيئة العمل الحالية أي مولّد أو خدمة صوت عربي نسائي عالي الجودة
يمكن الوصول إليها (لا اتصال بأي مزود صوت مدفوع/مفتاح API، وسياسة الشبكة في
هذه البيئة تحجب معظم مزودي الصوت السحابية بما فيها مصادر النماذج الصوتية
المحلية عالية الجودة) - لذا لم تُدرَج ملفات صوتية اصطناعية رديئة (روبوتية)
بدلًا عنها، لأن ذلك يخالف صراحة متطلبات الجودة المطلوبة. الكود جاهز
بالكامل لقراءة الملفات التالية بمجرد إضافتها هنا بصيغة MP3 (44.1kHz)، بدون
أي تعديل على الكود - إن لم يجد الملف فسيتجاهله بصمت ويكتفي بالمؤثر الصوتي
المولَّف (WebAudio) وحركة الشخصية.

## لماذا لم تُنشأ الملفات فعليًا في هذه البيئة

- لا يوجد أي مفتاح API لأي مزود صوت (ElevenLabs, Google Cloud TTS, Azure,
  Amazon Polly, OpenAI TTS...)، ولا صلاحية لإنشاء واحد بشكل آمن بدون طلب
  ذلك من صاحبة الحساب (وهو ما طُلب تحديدًا تجنّبه).
- سياسة شبكة هذه البيئة تحجب تحميل نماذج صوت محلية عالية الجودة أيضًا
  (مثل Piper TTS) لأن ملفات النماذج (.onnx) تُستضاف على مضيفات محجوبة
  بالسياسة (huggingface.co وGitHub Releases).
- الحلول المتاحة فعليًا بدون هذه القيود (Web Speech API المدمج في
  المتصفح، أو محرّكات توليف كلاسيكية مثل espeak) تُنتج صوتًا اصطناعيًا/
  روبوتيًا صراحة - وهذا مستبعَد صراحة من متطلبات الجودة المطلوبة، فلم
  يُستخدم تجنبًا لتقديم نتيجة لا تفي بالمطلوب فعليًا.

## كيف تُضاف الملفات لاحقًا (بلا أي تعديل على الكود)

أي من هذه الطرق يعمل فور توفره:
1. تسجيل العبارات باستخدام أي خدمة صوت بشري عالي الجودة تختارينها (على
   سبيل المثال ElevenLabs أو Google Cloud Text-to-Speech، اللذان يدعمان
   العربية بصوت نسائي طبيعي) خارج هذه البيئة، ثم رفع ملفات MP3 الناتجة.
2. تسجيل صوتي فعلي (معلمة أو معلّقة صوتية) بنفس الأسماء أعلاه بالضبط.

بمجرد وجود الملف بالاسم الصحيح داخل `public/audio/voice/`، يعمل تلقائيًا
في كل مكان (Master/Voice/SFX Volume، Mute، Quiet Mode، Reduced Motion،
Ducking تلقائي أثناء تشغيل العبارة) بدون أي تغيير إضافي على الكود.
